# MCreator Fabric 26.1.1 Generator

A fork of the [MCreator Fabric Generator](https://github.com/Goldorion/Fabric-Generator-MCreator) adding support for **26.1.1** (Fabric).

## Why?

I wanted to create a mod in 26.1.1 but since there was no plugin support this version, I had to add support myself.

This fork just updates the Gradle config, Fabric metadata, workspace setup, dependencies and version.

## Important

- This is made for MCreator **26.2**
- Only supports **26.1.1** (Fabric)
- Mods you make with this plugin require Fabric API
- This plugin is not affiliated with MCreator, Fabric, or Mojang

## How to download

1. Go to the "Releases" tab and download the latest version.
2. Open MCreator and head to the Plugin Manager (You can find this in the settings).
3. In the Plugin Manager, press on "Open plugins folder".
4. Now drag the zip from Finder into the plugins folder.
